# Landing de prueba · Túnel de acceso UPB

Archivos de la propuesta de Integración AV para la Invitación privada AF-OD-319.

- `index.html`: la landing (todo el diseño, los logos y los scripts van dentro de este archivo).
- `documentos/`: los PDF que enlaza la landing. **Deben subirse junto con el index.html**, con la misma estructura de carpetas y sin cambiar los nombres.

## Publicar con GitHub Pages
1. Suba `index.html`, `.nojekyll` y la carpeta `documentos` a la raíz del repositorio.
2. En el repositorio: Settings > Pages > Source: Deploy from a branch > Branch: `main` / carpeta `/ (root)` > Save.
3. En uno o dos minutos GitHub muestra la dirección de la página.

Nota de confidencialidad: el contenido de la propuesta es confidencial para las partes. En un repositorio público cualquiera con el enlace puede verlo.
